# AIGC Research 主页内容策划（中文版）

## 1. 定位与目标

### 1.1 主页定位

AIGC Research 主页不应仅是一个论文与链接的陈列页，而应成为一个能够同时传达以下三层信息的研究主页：

- 我们是谁：一个聚焦创意人工智能、影视动画生成与底层智能研究的研究计划。
- 我们在做什么：围绕“通用创意智能”与“智能创意工作流”展开长期探索。
- 我们为什么值得关注：既有面向前沿学术问题的研究深度，也有面向真实创作流程的工程落地能力。

### 1.2 用户感知目标

希望访问者在进入主页后的短时间内形成以下印象：

- 这是一个方向清晰、叙事完整、具有长期愿景的研究团队。
- 这不是泛泛的 AIGC 介绍，而是明确聚焦“创意智能”与“影视级内容生成”的研究计划。
- 团队既重视论文、基准、模型，也重视工作流、工具链、开源生态与真实创作场景。

### 1.3 建议整体气质

- 气质关键词：克制、前沿、电影感、研究性、工程感。
- 文案风格：避免口号堆砌，强调“问题定义 - 研究路径 - 已有成果 - 持续推进”。
- 页面节奏：先讲愿景，再讲研究方向，再讲成果与动态，最后讲团队与合作。

## 4. 研究计划总述文案

### 4.1 标题建议

**研究核心理念**

### 4.2 正文策划稿

秉持“以 AIGC 技术赋能艺术创作与内容生产，开启独立创作时代”的核心理念，本计划选择以“影视级动画”作为研究切入点。电影是视听艺术的综合载体，天然融合音乐、画面、色彩、叙事、动效与情感等多重创作要素，为人工智能理解“创作”提供了极具代表性的多模态样本。

我们强调“影视级”与“电影级”，并非单纯追求更高分辨率或更复杂的生成效果，而是强调创作中的整体表达质量，包括镜头语言、视听协同、叙事节奏、角色一致性、动作连续性与情感传达等。只有在这一高标准下推进研究，生成式人工智能才有机会真正进入专业内容生产场景，并反过来推动创作范式本身的升级。

## 5. 研究方向文案

### 5.1 总标题建议

**具体研究方向**

### 5.2 总引导文案

未来研究将围绕“通用创意智能”与“智能创意工作流”两大维度协同推进。前者关注机器创造力的边界，后者关注人类创造力的释放方式。二者并行推进，共同构成从创意理解到创意生产的完整研究闭环。

### 5.3 方向一：通用创意智能

#### 标题建议

**通用创意智能（General Creative Intelligence / Agent）**

#### 文案策划稿

本方向从“理解人类创作行为”的角度出发，关注 AI 如何获得在创作中进行顶层设计的能力。导演在构思叙事作品时，本质上是在脑海中同时组织声音、画面、动作、节奏与故事逻辑，进行跨模态的整体想象。视听艺术的真正魅力，也恰恰来自音乐、视觉、色彩、文本叙事、动态效果与情感表达之间的有机融合。

因此，本方向的核心问题不只是“如何生成素材”，而是“如何理解创作”。具体而言，我们将重点研究多模态感知、跨模态语义对齐、设计元素建模、美学认知与创作推理等关键问题，目标是赋予 AI 面向创作顶层设计的感知与推理能力，使其从被动生成工具逐步演化为具有设计思维的创意智能体。

#### 可拆成的关键词标签

- 多模态感知
- 跨模态设计对齐
- 创作推理
- 美学认知
- 设计思维智能体

### 5.4 方向二：智能创意工作流

#### 标题建议

**智能创意工作流（Intelligent Creative Workflow）**

#### 文案策划稿

本方向从“数字艺术资产的高效生产”出发，关注如何将创意智能体真正应用到内容生产流程中，以减少重复性劳动、提升创作效率，并拓展艺术家与模型之间的交互方式。针对传统 2D / 3D 动画制作中耗时费力的机械性环节，例如视觉预览、冷启动 3D 建模、手工补间帧、多镜头衔接与素材重组等，我们希望探索更加自动化、智能化、多样化的人机协同方案。

该方向覆盖从一维音频、二维图像、三维几何资产到四维视频的全数据形态，并尝试打破当前主流生成式系统单一的“图文驱动”范式，构建更加贴近影视动画创作实际、更符合艺术家直觉的多模态交互机制。我们的目标不是让艺术家适应工具，而是让工具逐步适应创作，让生成式 AI 深度融入现有工业化流水线，推动内容生产从繁琐的“工作流”走向更加纯粹的“创意流”。

#### 可拆成的关键词标签

- 创意智能体落地
- 2D / 3D / 4D 内容生产
- 多模态交互
- 影视动画工作流
- 从 Workflow 到 Creative Flow

## 6. 底层基础研究文案

### 6.1 总标题建议

**底层基础研究：可解释性与类脑计算**

### 6.2 总引导文案

为了支撑上述应用研究，我们同样重视 AI 的底层理论建设。我们拒绝将生成式模型仅仅视为不可分析、不可理解的“黑盒”，而是希望从模型机理、计算效率与脑科学启发三个层面，为下一代创意人工智能奠定更坚实的理论基础。

### 6.3 方向一：生成式大模型的可量化 / 可解释性研究

#### 文案策划稿

本方向关注当前主流生成式大模型的内部机理，尝试从微观、中观、宏观三个尺度进行系统分析。

- 微观层面：研究神经元激活表征、局部特征提取与语义编码机制。
- 中观层面：分析子网络、注意力模块与信息流在模型内部的协同方式。
- 宏观层面：探索模型整体的泛化边界、涌现能力、表示效率与能量损耗。

其核心意义在于，通过揭示模型内在工作机制，反向指导模型架构优化、训练机制设计与轻量化部署路径，推动“以小博大、事半功倍”的高效计算范式。

### 6.4 方向二：计算神经科学与交叉创新

#### 标题建议

**计算神经科学与交叉创新（AI for Science）**

#### 文案策划稿

本方向借鉴神经生物学与认知科学成果，开展面向人工智能与神经科学双向赋能的交叉研究。

一方面，我们尝试将前沿神经科学理论引入人工智能建模，围绕大脑不同功能区与脑网络构建可计算的数学模型与神经网络算法，寻求下一代 AI 架构层面的突破。

另一方面，我们也希望利用先进的生成式 AI 技术反向辅助神经科学研究，帮助分析脑数据、建模神经机制、发现潜在规律，从而在 AI for Neuroscience 方向中识别真正值得长期投入的重要科学问题。

#### 可拆成的双向表述

- 向内借鉴：从脑科学获取启发，推进类脑智能建模。
- 向外赋能：以生成式 AI 支持神经科学研究与发现。

### 7.3 成果卡片文案建议

#### 1. ViStoryBench

**ViStoryBench: A Comprehensive Benchmark Suite for Story Visualization**

一句话定位：
面向定制化视觉故事讲述的综合性基准测试，聚焦电影生成中的核心问题。

中文简介建议：
ViStoryBench 针对视觉叙事生成任务构建了一套系统性的评测框架，用于衡量模型在角色一致性、风格稳定性、剧情对齐、构图质量与故事可视化方面的真实能力。它不仅是一个 benchmark，也是在重新定义“影视叙事生成究竟该如何被评估”。

建议按钮：

- Tech Report
- Code
- Dataset
- Project Page
- Browse Results

#### 2. StyleMe3D

**StyleMe3D: Stylization with Disentangled Priors by Multiple Encoders on 3D Gaussians**

一句话定位：
面向 3D 创意表达的风格化研究，强调可控性、交互性与可扩展性。

中文简介建议：
StyleMe3D 关注 3D 高斯表示下的风格化生成问题，探索如何通过多编码器与解耦先验实现更稳定、更灵活的风格控制。该项目体现了团队对 3D 作为创作媒介的长期判断，即 3D 不仅可生成，更应可编辑、可控制、可持续扩展。

建议按钮：

- Tech Report
- Project Page
- Code

**ShotStudio: Towards Comprehensive Film Creation | From Creativity to Filmmaking**

一句话定位：
面向完整影视创作流程的 AIGC 框架探索。

中文简介建议：
ShotStudio 试图将创意理解、镜头组织、素材生成与创作流程协同串联起来，作为面向未来电影生成与影视创作系统的重要框架原型。它不是一个单点模型，而是一个不断演化的创意工作流实验场。

#### 5. Act2Cut

**Act2Cut: Continuous Multi-Shot Video Narrative Match on Action**

一句话定位：
面向多镜头视频叙事的动作连续性建模框架。

中文简介建议：
Act2Cut 聚焦电影语言中极为关键却长期被忽视的“动作匹配剪辑”问题，尝试让生成式视频系统真正具备跨镜头动作连续性理解能力。相比只关注表层视觉一致性的多镜头生成方法，该项目更强调叙事动作、镜头切换与电影语法之间的协同关系，是“影视级生成”路线中的关键技术预告。

建议展示要点：

- 支持 Text / Image / Video 驱动的多镜头生成与下一镜预测
- 聚焦 Match on Action / Action-Cut
- 强调镜头连续性而非单帧视觉相似

建议按钮：

- Paper / Preprint

## 17. 可直接作为首页的中文版精简稿

如果希望先快速上线，可以直接使用下面这版更接近首页成稿的内容。

### 标题

**创意人工智能研究计划：从“工作流”走向“创意流”**

### 副标题

我们致力于推动 AIGC 技术赋能艺术创作与内容生产，围绕“通用创意智能”与“智能创意工作流”开展持续研究，探索机器如何理解创作、参与创作，并服务未来影视级内容生产。

### 研究理念

本计划秉持“以 AIGC 技术赋能艺术创作与内容生产，开启独立创作时代”的核心理念，以“影视级动画”作为研究切入点。电影作为视听艺术的综合载体，融合了音乐、画面、色彩、叙事、动效与情感等丰富要素，是人工智能理解复杂创作行为的重要多模态样本。我们强调“电影级”创作标准，关注的不只是生成质量本身，更包括镜头语言、动作连续性、视听协同与情感表达等真正决定作品完成度的关键维度。

### 研究方向

我们的研究主要围绕两个方向展开。

其一是通用创意智能。我们关注 AI 如何从“素材生成器”走向“具有设计思维的创意智能体”，重点研究多模态感知、跨模态设计元素对齐、美学认知与创作推理，使模型能够理解声音、画面、叙事与情绪之间的复杂关系。

其二是智能创意工作流。我们关注如何将创意智能体真正引入内容生产流程，减少 2D / 3D 动画制作中的重复劳动，探索从音频、图像、几何资产到视频的全链路智能协同，并推动生成式 AI 从繁琐工作流走向更加自然的创意流。

### 基础研究

为了支撑上述应用，我们也持续开展底层基础研究，重点聚焦生成式大模型的可量化 / 可解释性分析，以及受神经科学启发的类脑计算与 AI for Science 探索。我们希望不仅使用模型，也理解模型；不仅训练更大的系统，也寻找更高效、更本质的下一代智能路径。

### 代表成果

- `ViStoryBench`：面向视觉故事讲述的综合性基准测试，重新定义影视叙事生成的评测方式。
- `StyleMe3D`：面向 3D 创意表达的风格化研究，强调可控、可交互、可扩展。
- `ShotStudio`：面向完整影视创作流程的 AIGC 框架探索。
- `Act2Cut`：聚焦多镜头视频叙事中的动作连续性与电影化镜头衔接。
- `Awesome-PaperDaily`：持续追踪 AIGC 前沿进展的开源知识整理项目。

### 团队

团队成员包括庄才林、胡耀淇、董政，并与工业界导师程巍、学术界导师夏清零保持持续合作。我们欢迎对创意人工智能、影视内容生成、开源共建与跨学科研究感兴趣的同行与我们交流合作。
